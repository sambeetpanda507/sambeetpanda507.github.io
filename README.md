# Sambeet Sekhar Panda — Portfolio

A fast, static developer portfolio built with Astro and designed for GitHub Pages.

## Tech stack

- Astro
- TypeScript
- GitHub Actions
- GitHub Pages

## Local development

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run check
npm run build
npm run preview
```

## Deployment

Pushes to `main` deploy through `.github/workflows/deploy.yml` to:

```text
https://sambeetpanda507.github.io
```
